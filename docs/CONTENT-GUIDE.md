# Как делать главу

Эталон — глава **«Причастие»** (`src/chapters/prichastie/`). Новую главу делать по ней.

## 1. Материал

1. Найти тему во всех книгах из `docs/SOURCES.md` (Розенталь — основной; Адамчик, Наумова, Сидорова, Классический справочник; сборники — для упражнений).
2. Составить полный список: правила, все исключения, тонкости, спорные случаи, типичные ошибки, примеры.
3. Сверить с «Правилами русской орфографии и пунктуации» (2006). Где пособия расходятся — дать норму Правил 2006 и блок «Норма сегодня».

## 2. Авторское право

- **Пересказывать своими словами.** Нельзя копировать формулировки правил, определения, тексты упражнений, связные тексты и диктанты из книг.
- Можно: факты, правила по сути, списки слов-исключений, отдельные слова и короткие словосочетания как примеры.
- Тексты для диктантов и связных упражнений — писать самостоятельно.
- Внизу главы — `src` («По книгам: …») и `bookref` («Ещё упражнения на эту тему: Розенталь, § 50, упр. 235»).

## 3. Уроки

Глава — 4–8 уроков. Для каждого урока поля `h`, `lite`, `deep`, `hint`, `easy`, `fix` (см. ARCHITECTURE.md).

- `h` — полная теория: всё, «до идеала». Подзаголовки `<h4>` — короткие (попадают в оглавление). Каждое правило — с примерами `<span class="ex">`. Морфемы и буквы — `<b class="m">`. Таблицы — в `<div class="tblw"><table class="bktbl">`.
- В каждом уроке — **минимум одна интерактивная схема** `{{lab:id}}`: кластер признаков, таблица-матрица, конструктор, пошаговый алгоритм (вопрос → ответ → следующий вопрос), сравнение пар, расстановка знаков.
- `lite` — режим «Проще»: то же правило простыми словами, **по шагам** («Как узнать — два шага», «Проверить три вещи по порядку»), с примером на каждый шаг и блоком «Запомнить». Без исключений второго ряда, но и без упрощений, которые неверны для заметной группы слов. Не называть разделы словом «вид», если речь не о виде глагола. Без `<h4>` (подзаголовки — `<p><b>…</b></p>`). Схемы оставить.
- `deep` — тонкости, исторические и спорные случаи, переход в другие части речи.
- `easy` — одно объяснение «на пальцах»; `fix` — что делать, если не получается (пошагово).
- Блоки: `bkey` «Главное» в конце урока; `bnorm` «Частая ошибка»; `btip` «Интересно».

## 4. Тренажёр (`bank.js`)

- 20–35 заданий на урок, всего 150–200 на главу.
- Каждое задание — один **бесспорный** ответ. Если ответ зависит от контекста — дать контекст в `w`. Если допустимы оба варианта — задание не брать.
- `why` — короткое объяснение (почему так), его видит ученик после ответа.
- Наборы вариантов (`opts`) выносить в константы (как `K4`, `PA`, `SR`, `CM` в «Причастии»): задания с одинаковым набором попадают в режим «Столбики».

## 4а. Тесты (`tests.js`)

Тест — **контроль без подсказок**, отдельно от тренажёра. Тест по уроку — 6 вопросов урока, итоговый — 12 по всей главе (минимум по одному из каждого урока). Оценка 2–5: от 90% — 5, от 75% — 4, от 50% — 3. **Глава завершена, когда все тесты сданы на 3 и выше.**

- Вопрос («слот») описывает вид задания и набор примеров; при каждом запуске берётся случайная формулировка из `q`, случайный пример из `items`, варианты перемешиваются. Поэтому у каждого слота — **2–3 формулировки** и по возможности **много примеров**.
- Виды `k`: `one` — один ответ; `many` — все верные; `type` — вписать ответ (`_` — пропуск, сравнение без учёта регистра и ё/е); `sort` — разложить по группам.
- На урок — не меньше 6 слотов разных видов: распознать, объяснить «почему», найти ошибку, вписать букву или форму, разложить по группам.
- `why` — короткое пояснение, его ученик видит в разборе ошибок вместе со ссылкой «Повторить урок».
- Каждый ответ бесспорный. Если у слота `n` (показать n вариантов из большого списка), ни один вариант списка не должен оказаться верным для другого примера этого слота.
- Варианты-«ловушки» — типичные ошибки учеников, а не бессмыслица.

## 5. Упражнения в тетрадь (`classic.js`)

**Принцип: полный спектр.** Упражнений должно быть столько и таких разных, чтобы учителю всегда было из чего выбрать, — как у Розенталя, только шире. Каждое правило отрабатывается упражнениями всех видов, на всём материале и на всех уровнях сложности. Чем больше выбор, тем лучше; повторов по сути быть не должно.

Каждое упражнение описывается по четырём параметрам — и в главе должны быть заполнены все клетки, где это возможно:

1. **Охват**
   - *узкое* — один случай правила или одно исключение (только -ян- с исключениями; только «стеклянный, оловянный, деревянный»);
   - *по уроку* — правило целиком;
   - *широкое* — вся глава вперемешку;
   - *комплексное* — несколько тем сразу: орфография вместе с пунктуацией и разбором, материал прошлых глав (повторение «по спирали»).
2. **Вид действия**
   - узнать и выписать; распределить по столбикам и группам; выбрать из вариантов;
   - вставить буквы или знаки, раскрыть скобки; обозначить орфограмму графически; объяснить написание;
   - подобрать примеры, проверочные или однокоренные слова; образовать формы и слова;
   - преобразовать (заменить, перестроить предложение, полное — в краткое и т. п.); составить словосочетания или предложения по схеме;
   - сравнить и разграничить похожие случаи; найти и исправить ошибки; отредактировать текст;
   - разбор: фонетический, морфемный, словообразовательный, морфологический, синтаксический, пунктуационный;
   - заполнить или составить таблицу, схему, алгоритм;
   - диктанты: словарный, выборочный, распределительный, предупредительный, объяснительный, творческий, свободный, контрольный;
   - изложение; сочинение-миниатюра с заданием на тему; комплексный анализ текста;
   - задания в формате итоговых тестов; лингвистические задачи и мини-исследования (для сильных).
3. **Материал**: слова → словосочетания → предложения → связный текст (в том числе отрывки из классики — своими выборками, без копирования упражнений из книг).
4. **Сложность** `st` по 5 звёздам:
   - ★ — узнать/выписать по образцу;
   - ★★ — вставить буквы с одним правилом;
   - ★★★ — несколько правил, объяснить;
   - ★★★★ — разграничить похожие случаи, найти ошибки, преобразовать;
   - ★★★★★ — диктант, сочинение, связный текст, составить текст по заданию.

Объём: не меньше 12–20 упражнений на урок и блок повторения с широкими и комплексными упражнениями; на главу — 100 и больше. Классических упражнений всегда больше, чем заданий тренажёра.

Оформление:
- Формулировки — инфинитивом, как в сборниках: «Вставить пропущенные буквы. Объяснить написание».
- `obr` — образец выполнения (обязателен для ★–★★★). `key` — полный ключ.
- **`n` — постоянный номер упражнения.** По нему учитель задаёт домашку и по нему же хранятся отметки «выполнено». Номер не менять и не переиспользовать: новое упражнение получает следующий свободный номер главы, даже если стоит в середине (порядок показа задаёт урок `l`). Удалённый номер больше не занимать.
- Номера книг (`bookref`) показываются отдельно, с пометкой «номера по той книге», чтобы их не путали с нашими.

## 6. Подключение

1. Файлы главы — в `src/chapters/<id>/`.
2. В `tools/build.py` добавить файлы в `JS` (lessons → bank → classic → labs; при необходимости `index.js` со сборкой главы).
3. В конце `classic.js` (или `index.js`): `Object.assign(X,{bank,classic,lnames,bookref}); CHAPTERS.<id>=X;`
4. Схемы — `Object.assign(LABS,{…})`, обработчики кликов — в `screens.js` рядом с остальными.
5. В `PARTS` поставить `ready:1`.
6. Добавить термины в `src/data/glossary.js` (с безопасным `f`), трудные слова — в `src/data/spelling-words.js`, при желании — статьи в умный словарь.

## 7. Проверка (обязательно)

1. **Независимая проверка содержания** отдельным агентом, который не писал главу: правила, исключения, ключи, двусмысленные задания, опечатки, латиница внутри кириллицы, звёзды. Агенту давать файлы, а не свои выводы. Править по его списку.
2. `python3 tools/build.py && node tools/test/smoke.js && node tools/test/layout.js` — без ошибок.
3. Посмотреть скриншоты схем на телефоне (390 px) и на компьютере (1280 px).

## Типичные ловушки (уже встречались)

- `\b` в регулярных выражениях не работает с кириллицей — использовать `(?=\s|$)` или `[^а-яё]`.
- Ё: в заданиях на «ё после шипящих» писать ё; в остальных — как в Правилах.
- «Недо-» со всеми частями речи пишется слитно — не путать с «не» + «до».
- Слова с двумя нормами (развешанный/развешенный в значении «повешенный в разных местах», мерять/мучать) — не давать как задания.
