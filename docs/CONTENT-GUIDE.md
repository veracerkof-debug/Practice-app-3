# Как делать главу

Эталон — глава **«Причастие»** (`src/chapters/prichastie/`). Новую главу делать по ней.

## 1. Материал

1. Найти тему во всех книгах из `docs/SOURCES.md` (Розенталь — основной; Адамчик, Наумова, Сидорова, Классический справочник; сборники — для упражнений).
2. Составить полный список: правила, все исключения, тонкости, спорные случаи, типичные ошибки, примеры.
3. Сверить с «Правилами русской орфографии и пунктуации» (2006). Где пособия расходятся — дать норму Правил 2006 и блок «Норма сегодня».

## 2. Авторское право

- **Пересказывать своими словами.** Нельзя копировать формулировки правил, определения, тексты упражнений, связные тексты и диктанты из книг.
- Можно: факты, правила по сути, списки слов-исключений, отдельные слова и короткие словосочетания как примеры.
- Тексты для диктантов и связных упражнений — писать самостоятельно.
- Внизу главы — `src` («По книгам: …») и `bookref` («Ещё упражнения на эту тему: Розенталь, § 50, упр. 235»).

## 3. Уроки

Глава — 4–8 уроков. Для каждого урока поля `h`, `lite`, `deep`, `hint`, `easy`, `fix` (см. ARCHITECTURE.md).

- `h` — полная теория: всё, «до идеала». Подзаголовки `<h4>` — короткие (попадают в оглавление). Каждое правило — с примерами `<span class="ex">`. Морфемы и буквы — `<b class="m">`. Таблицы — в `<div class="tblw"><table class="bktbl">`.
- В каждом уроке — **минимум одна интерактивная схема** `{{lab:id}}`: кластер признаков, таблица-матрица, конструктор, пошаговый алгоритм (вопрос → ответ → следующий вопрос), сравнение пар, расстановка знаков.
- `lite` — то же правило в 3–6 предложениях, без исключений второго ряда, простыми словами. Схемы можно оставить.
- `deep` — тонкости, исторические и спорные случаи, переход в другие части речи.
- `easy` — одно объяснение «на пальцах»; `fix` — что делать, если не получается (пошагово).
- Блоки: `bkey` «Главное» в конце урока; `bnorm` «Частая ошибка»; `btip` «Интересно».

## 4. Тренажёр (`bank.js`)

- 20–35 заданий на урок, всего 150–200 на главу.
- Каждое задание — один **бесспорный** ответ. Если ответ зависит от контекста — дать контекст в `w`. Если допустимы оба варианта — задание не брать.
- `why` — короткое объяснение (почему так), его видит ученик после ответа.
- Наборы вариантов (`opts`) выносить в константы (как `K4`, `PA`, `SR`, `CM` в «Причастии»): задания с одинаковым набором попадают в режим «Столбики».

## 5. Упражнения в тетрадь (`classic.js`)

- 4–6 упражнений на урок + 4–8 на повторение; всего 35–50 на главу (больше, чем в тренажёре по числу действий).
- Формулировки — инфинитивом, как в сборниках: «Вставить пропущенные буквы. Объяснить написание».
- Сложность `st` по 5 звёздам:
  - ★ — узнать/выписать по образцу;
  - ★★ — вставить буквы с одним правилом;
  - ★★★ — несколько правил, объяснить;
  - ★★★★ — разграничить похожие случаи, найти ошибки, преобразовать;
  - ★★★★★ — диктант, сочинение, связный текст, составить текст по заданию.
- `obr` — образец выполнения (обязателен для ★–★★★). `key` — полный ключ.

## 6. Подключение

1. Файлы главы — в `src/chapters/<id>/`.
2. В `tools/build.py` добавить файлы в `JS` (lessons → bank → classic → labs; при необходимости `index.js` со сборкой главы).
3. В конце `classic.js` (или `index.js`): `Object.assign(X,{bank,classic,lnames,bookref}); CHAPTERS.<id>=X;`
4. Схемы — `Object.assign(LABS,{…})`, обработчики кликов — в `screens.js` рядом с остальными.
5. В `PARTS` поставить `ready:1`.
6. Добавить термины в `src/data/glossary.js` (с безопасным `f`), трудные слова — в `src/data/spelling-words.js`, при желании — статьи в умный словарь.

## 7. Проверка (обязательно)

1. **Независимая проверка содержания** отдельным агентом, который не писал главу: правила, исключения, ключи, двусмысленные задания, опечатки, латиница внутри кириллицы, звёзды. Агенту давать файлы, а не свои выводы. Править по его списку.
2. `python3 tools/build.py && node tools/test/smoke.js && node tools/test/layout.js` — без ошибок.
3. Посмотреть скриншоты схем на телефоне (390 px) и на компьютере (1280 px).

## Типичные ловушки (уже встречались)

- `\b` в регулярных выражениях не работает с кириллицей — использовать `(?=\s|$)` или `[^а-яё]`.
- Ё: в заданиях на «ё после шипящих» писать ё; в остальных — как в Правилах.
- «Недо-» со всеми частями речи пишется слитно — не путать с «не» + «до».
- Слова с двумя нормами (развешанный/развешенный в значении «повешенный в разных местах», мерять/мучать) — не давать как задания.
