## Порядок работы (решение владельца, ноябрь 2026)
Сначала — **хороший учебник** (этап A), и только потом — **сервер и кабинет учителя** (этапы B–C), а рядом с ними — **связь и синхронизация** (этап D). Всё, что ученик делает в учебнике, сначала полностью работает на устройстве; синхронизация потом лишь отправляет это учителю.

## Этап B. Сервер учителя — своё приложение
- У каждого учителя **свой сервер**: приложение «Сервер учебника» для **Windows, macOS и Linux**, ставится одним установщиком (у владельца — ноутбук на Linux). Данных немного: база SQLite в одном файле.
- Простое окно: «Запустить / Остановить», адрес и **QR-код для учеников**, состояние подключений, **резервные копии** по расписанию (в папку или на флешку) и восстановление в один клик.
- **Доступ из интернета**: дома ноутбук за роутером и без постоянного адреса, поэтому нужен встроенный туннель или настройка роутера; обязательно HTTPS, иначе сайт на GitHub Pages не сможет обращаться к серверу. Всё — одной кнопкой, без ручной настройки.
- Данные хранятся **только на сервере учителя** (вопрос хранения персональных данных детей решается так).
- Если сервер выключен или ноутбук спит — учебник копит данные на телефоне и отправляет их позже.

## Этап C. Кабинет учителя — журнал и управление
- **Классы и группы**: добавить любой класс; добавлять и удалять учеников; раздать аккаунты (код класса, имя, PIN; карточки-листочки для печати). Персональные настройки у каждого учителя и группы.
- **Журнал**: оценки (2–5; учитель ставит сам, статистика и тесты — подсказка), посещаемость, заметки о поведении, комментарии.
- **КТП**: загрузка календарно-тематического плана; урок по дате связан с главой учебника; домашнее задание — из КТП (ссылки на упражнения уже есть).
- **Статистика ученика**: время, занятия, темы, ошибки, тесты, выполненные упражнения. Учитель может **откатить статистику ученика и отменить засчитанные часы**.
- **Рейтинговая таблица** класса: средний балл, проведённое время, занятия, и **старание** — рост точности и регулярность, а не только время. Учитель выбирает, что показывать.
- Выгрузка в Excel, печать.
- Интерфейс — интуитивный, гибкий, стабильный: с ним работают каждый день.

## Этап D. Связь и синхронизация
- Ученик подключается к серверу своего учителя по QR-коду или ссылке (в ней адрес сервера и код класса).
- Учебник работает без сети как раньше; статистика, тесты и отметки отправляются, когда сервер доступен. Конфликты и повторная отправка — без потерь.
- **Ссылки для родителей** — только просмотр, без регистрации: персональную ссылку может создать **ученик** (свою успеваемость подробно) и **учитель** (на любого ученика); учитель может отключить ссылку и создать новую. Общая рейтинговая таблица — средний балл и время за учебником.
- Правило «без сети» снято (решение владельца): сеть нужна только для синхронизации, учебник по-прежнему работает офлайн.

## Защита данных пользователей (решение владельца, ноябрь 2026)
Абсолютной защиты не бывает: кто захочет жульничать, взломать или перехватить — найдёт способ. Но **базовая защита данных и их передачи обязательна** — настолько хорошая, насколько это в наших силах. Закладывается в этапы B–D с самого начала, а не «потом».

**Минимум данных.** У учеников просим только **имя и фамилию** (и код класса). Никаких телефонов, почты, дат рождения, адресов, фото, документов. У учителя — только то, что нужно для входа. Имя, фамилия и оценки — не самые чувствительные сведения, но это данные детей, поэтому обращаемся с ними бережно.

**Передача.**
- Только HTTPS (TLS) между учебником и сервером учителя; обычный HTTP сервер не принимает.
- Сервер отвечает только учебнику (ограничение CORS), проверяет все входящие данные, ограничивает частоту попыток входа.

**Хранение на сервере учителя.**
- Пароли и PIN — только в виде стойкого хеша (Argon2 или bcrypt), никогда открытым текстом.
- База данных и резервные копии — зашифрованы (ключ — пароль учителя); копия, унесённая на флешке, без пароля бесполезна.
- Данные не уходят никуда, кроме сервера учителя: никакой сторонней аналитики, рекламы, счётчиков.

**Доступ.**
- Учитель видит только свои классы; ученик — только себя и общий рейтинг класса; родитель по ссылке — только своего ребёнка.
- Ссылки для родителей — длинный случайный токен, который нельзя угадать; ссылку можно отключить и выпустить новую; по желанию — срок действия.
- Сеансы входа с ограниченным сроком; выход на устройстве стирает токен.
- Журнал изменений оценок и статистики (кто и когда менял) — чтобы откат и правки были прозрачны.

**Удаление.** Удалили ученика из класса — его данные удаляются с сервера (или по запросу владельца данных). На телефоне ученика — кнопка «Выйти и стереть данные».

**Обновления.** Серверное приложение получает обновления безопасности; зависимости — только проверенные и минимальные.

## Защита от накруток (базовая, во всех этапах)
- Время считается только активное: 5 минут без действий — таймер стоит, эти минуты не засчитываются.
- Отметка «выполнено» в упражнениях в тетрадь — самоотчёт ученика; объективные цифры — тесты, тренажёр, диктанты.
- Учитель может откатить статистику. Главное — оценки; статистика — условный показатель вовлечённости.
