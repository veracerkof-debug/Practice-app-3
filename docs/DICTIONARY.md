# Умный словарь

Цель — один словарь, где у каждого слова есть всё: значение, ударение, части речи и формы, **морфемный разбор** (со школьными значками и разбором по шагам), **словообразование** (цепочка и способ), однокоренные слова, синонимы, антонимы, паронимы, фразеологизмы, орфограммы со ссылками на правила учебника.

Сейчас — **пилот на 50 слов** (слова из глав «Н и НН» и «Причастие»). Следующий шаг — школьное ядро 3–5 тыс. слов.

## Источники и лицензии

| что | откуда | лицензия |
|---|---|---|
| значения, ударение | Русский Викисловарь, выгрузка 2022 г. (StarDict, 327 829 слов) из репозитория [Vuizur/ruwiktionary-htmldump-parser](https://github.com/Vuizur/ruwiktionary-htmldump-parser) (файл `Russian-Russian-dict.tar.gz`) | CC BY-SA |
| формы слов | OpenCorpora через `pymorphy3` + `pymorphy3-dicts-ru` | CC BY-SA |
| морфемы, словообразование, гнёзда, синонимы, орфограммы, упрощённые значения | пишутся заново (Claude по школьной традиции: Ладыженская/Разумовская, Розенталь) с независимой проверкой | наши |

Важно: данные под CC BY-SA требуют указать источник (есть внизу карточки) и распространять **сами словарные данные** под той же лицензией. Код и тексты учебника — под лицензией, которую выберет владелец.

Ожегова, Тихонова, Ефремову и др. **не копировать** — только сверяться.

Выгрузка Викисловаря не содержит морфемного разбора и синонимов (на самом сайте они есть, в эту выгрузку не попали). Сайт ru.wiktionary.org из облачной среды Claude недоступен; если понадобится свежая/полная выгрузка — скачать дамп `ruwiktionary-NS0-…-ENTERPRISE-HTML.json.tar.gz` с dumps.wikimedia.org/other/enterprise_html/ вручную.

## Пайплайн (`tools/dictionary/`)

```bash
# 1. данные Викисловаря (один раз)
git clone --depth 1 https://github.com/Vuizur/ruwiktionary-htmldump-parser /tmp/rw
mkdir -p .cache/wikt && tar xzf /tmp/rw/Russian-Russian-dict.tar.gz -C .cache/wikt
python3 tools/dictionary/stardict_to_pickle.py      # → .cache/wikt/E.pkl  {слово без ударения: [(с ударением, html)]}

# 2. выбрать слова и вытащить их значения/ударения
python3 tools/dictionary/pick.py words.txt          # → .cache/wikt/pilot_wikt.json

# 3. формы слов
pip install pymorphy3 pymorphy3-dicts-ru
python3 tools/dictionary/forms.py                   # → src/data/dictionary/forms.js

# 4. статьи пишутся по брифу tools/dictionary/BRIEF.md партиями по 25 слов (агентами),
#    затем — независимая проверка (см. ниже), правки, сборка.
```
`.cache/` в git не кладётся.

## Схема статьи

См. `docs/ARCHITECTURE.md` → «Умный словарь» и бриф `tools/dictionary/BRIEF.md` (там же правила: что включать в гнездо, как разбирать причастия, постфикс, нулевое окончание и т. д.).

Принятые решения по разбору (единые для всего словаря):
- основа — без окончания, без формообразующего суффикса инфинитива (-ть/-ти) и без постфикса -ся; суффиксы причастий входят в основу;
- в отглагольных словах на -анный/-янный/-аный выделять глагольный суффикс отдельно: жел-а-нн-ый, ков-а-н-ый, не-ча-я-нн-ый;
- в отымённых -ан-/-ян-/-янн-/-енн-/-онн- — одним суффиксом: кож-ан-ый, дерев-янн-ый;
- гнездо — только однокоренные в **современном** языке (дерево — деревня не однокоренные);
- синонимы/антонимы/паронимы — только бесспорные; пустой список лучше сомнительного;
- подписи частей речи в гнезде: `сущ.`, `прил.`, `глаг.`, `нареч.`, `прич.`.

## Проверка

После каждой партии — отдельный агент-рецензент с задачей вернуть правки в виде JSON-строк `{"w","field","new","why"}`; правки применяются скриптом. В пилоте рецензент исправил 9 статей из 50 (объяснение н в «глиняный», разбор «брить», лишний синоним у «брезжущий» и др.).

## Масштаб

- Веб-версия: школьное ядро 3–5 тыс. слов (≈ 2–4 МБ данных) — помещается в один файл.
- Android: можно подключить полную базу значений Викисловаря (≈ 25 МБ) в SQLite, а подробные статьи — только для ядра.
