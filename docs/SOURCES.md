# Источники

## Книги владельца (материал для пересказа)

Папка Google Drive владельца: https://drive.google.com/drive/folders/1DKohXuSS3KqXjCNQzA6brNQ6UvOYivUn

Основные:
- **Д. Э. Розенталь. Русский язык: учебное пособие** — основной источник норм (оцифрован владельцем в FB2).
- **Н. В. Адамчик. Самый полный курс русского языка** (FB2).
- **Наумова. Морфология простым языком** (FB2).
- **Сидорова. Русский язык для абитуриентов** (FB2).
- **Классический справочник по русскому языку** (PDF).
- **Правила русской орфографии и пунктуации** (2006; полный академический справочник).
- Сборники упражнений с комментариями, практический справочник (PDF).

FB2-версии четырёх книг лежат в проекте claude.ai «Работа в школе». Тексты книг в репозиторий **не кладутся** — только пересказ.

Ссылки на параграфы и номера упражнений книг даются в главах (`src`, `bookref`).
