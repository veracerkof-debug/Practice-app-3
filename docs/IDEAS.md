# Идеи: что взять у других интерактивных учебников

Разбор чужих проектов (ноябрь 2026) и предложения для нашего учебника. Это **черновик для обсуждения с владельцем**: что принято — переносится в `PRODUCT.md` и `ROADMAP.md`.

Наши ограничения, под которые подбирались идеи: один офлайн-файл, без сервера и без аккаунтов; ученики разного уровня; учитель задаёт домашку; телефон важнее компьютера.

## 1. Что смотрели и что там ценного

| Проект | Что у них работает | Что берём себе |
|---|---|---|
| **Khan Academy** | Уровни освоения навыка: «не начато → пробовал → знаком → уверенно → освоено». До «освоено» поднимает только проверочная работа (unit test / course challenge). Подсказки по шагам. | Уровни освоения правила вместо одной галочки «урок пройден»; лестница подсказок. |
| **IXL** | SmartScore 0–100 — не процент верных ответов: в конце ошибка стоит дороже, а 100 — только устойчивое знание. Входная диагностика сразу показывает, с чего начать. | Оценка освоения, которую нельзя «нащёлкать»; входная проверка по главе. |
| **Math Academy** | Граф знаний: темы связаны предпосылками. Повторение сложной темы засчитывается и простым темам внутри неё (FIRe), поэтому повторений нужно меньше. | Карта правил с предпосылками («перед этим уроком повтори…»); повторение «по спирали». |
| **Duolingo / Anki** | Интервальное повторение, короткие ежедневные сессии. | У нас уже есть карточки; добавить личную колоду ошибок. |
| **NoRedInk** | Учитель выдаёт задание классу и видит освоение по каждому правилу. Пока ученик не наберёт серию верных ответов, задание не закрывается. Предложения подбираются под интересы ученика (по отзывам, быстро приедается). | Задание «до освоения» в тренажёре; результат для учителя. Подбор по интересам — не берём. |
| **Skysmart, ЯКласс, РЭШ** | Учитель отправляет ссылку на задание, проверка автоматическая, результаты у учителя. Урок РЭШ построен как «мотивация → объяснение → тренировка → контроль». | Ссылки уже есть у упражнений в тетрадь, нужны и для тренажёра. Структура урока с проверкой в конце. |
| **Грамота.ру, «Тотальный диктант»** | Интерактивные диктанты: текст, подсчёт ошибок, показ верного написания, разбор текстов. Курсы подготовки к диктанту с контрольным в конце. | Интерактивный и аудиодиктант с разбором каждой ошибки и ссылкой на правило. |
| **«Решу ОГЭ / ЕГЭ»** | Банк заданий по номерам экзамена, сборка вариантов, ключи. | Метка «формат экзамена» у заданий; сборка варианта (после того, как выясним, какой экзамен нужен). |
| **Brilliant, «explorable explanations»** | Сначала попробуй сам, потом правило. Каждый шаг интерактивен, обратная связь сразу. | «Загадка урока» в начале; короткие проверки внутри теории (в «Н и НН» уже есть встроенные упражнения). |
| **Печатные сборники (Розенталь и др.)** | Огромный выбор упражнений, ключи, тексты классиков. | Принцип полного спектра уже записан. Важно: **тексты классиков, перешедшие в общественное достояние** (Пушкин, Толстой, Чехов…), можно брать дословно — это законный материал для диктантов и комплексных упражнений. |

## 2. Предложения — главные (по пользе)

### 2.1. Диктант с разбором ошибок ★★★★★
- **Аудиодиктант.** Учебник сам читает текст: по предложениям, с паузами, повтор по кнопке. Голос синтезирует браузер или телефон (Web Speech API, работает без интернета, если в системе есть русский голос). Ученик пишет в тетради или набирает текст на экране.
- **Сверка набранного.** Расхождения подсвечиваются, каждая ошибка подписана правилом со ссылкой на урок («Н и НН, урок 2»). Итог — число ошибок и оценка по школьной шкале.
- **Интерактивный текст с пропусками.** Связный текст, в нём пропуски букв и знаков, ответ выбирается касанием. Подходит для телефона.
- Виды: словарный, выборочный, распределительный, предупредительный, объяснительный, контрольный — по CONTENT-GUIDE.

### 2.2. «Мои ошибки» и повторение по спирали
- Слова и задания, в которых ученик ошибся (в тренажёре, диктанте, карточках), сами попадают в личную колоду «Мои ошибки» с интервальным повторением.
- **«10 минут в день»**: смесь из пройденного по всем главам. Ошибки и давно не повторённое идут первыми, плюс немного нового. Это повторение «по спирали» без усилий учителя.
- «Слабые места»: «чаще всего ошибки в исключениях -ян-» → ссылка на правило и узкое упражнение.

### 2.3. Освоение правила вместо галочки
- У каждого урока (правила) уровень: *не начато → знакомо → уверенно → освоено*. Он считается по тренажёру, а в конце урока появляется «Проверь себя» (5–8 заданий).
- Как у IXL и Khan Academy: «освоено» — только после проверочной работы и без ошибок в конце. Кнопка «Урок пройден» остаётся для тех, кто занимается по книге.
- В оглавлении — карта освоения по всем главам.

### 2.4. Инструменты учителя (без сервера)
- **Подборка задания**: учитель отмечает упражнения и задания тренажёра → получает одну ссылку и **печатный лист** (А4, с ключом на отдельной странице).
- **Контрольная в двух вариантах**: сборка из банка по выбранным урокам и звёздам, «Вариант 1 / Вариант 2», ключи, печать.
- **Результат ученика**: после задания по ссылке — экран результата и короткий **код проверки** (например, `7К-Р4Т2`). В коде зашиты задание, число верных ответов и дата. Учитель вводит код у себя и видит результат — без сервера и аккаунтов. Подделать можно, но трудно; для домашки этого достаточно. Автоматический сбор результатов всего класса без сервера невозможен — это отдельное решение (нужен бэкенд).

### 2.5. Карта правил
- Граф связей: «Н и НН в причастиях» опирается на «Образование причастий» и «Вид глагола».
- В начале урока: «Для этого урока нужно знать: … (проверить себя за 1 минуту)».
- Повторение сложной темы засчитывается простым темам внутри неё (как FIRe у Math Academy): меньше лишних повторений.

## 3. Предложения — второго ряда
- **Входная проверка по главе** (как диагностика IXL): 10 заданий → «уроки 1–2 можно пропустить, начните с 3».
- **Лестница подсказок** в тренажёре: 1) какое правило; 2) первый шаг алгоритма; 3) ответ с объяснением. В «Проще» лестница включена сразу.
- **«Почему так пишется?»** — поле на главной: ввести слово → найти его в словаре или словарике → показать орфограмму и правило.
- **Шпаргалка главы**: все правила главы на одной странице, для печати; каталог всех пошаговых алгоритмов.
- **«Загадка урока»**: урок начинается с вопроса, на который ученик пока не может ответить, — ответ даёт правило.
- **Удобство чтения**: размер шрифта; озвучка теории (тем же голосом, что в диктанте) — для слабых читателей; шрифт для учеников с дислексией.
- **Перенос прогресса**: экспорт и импорт файлом или кодом (смена телефона).
- **Режим «урок в классе»**: крупный шрифт, схема на весь экран для проектора.
- **Мягкая мотивация**: дни занятий подряд, без очков и рейтингов (решает владелец).

## 4. Чего не делать
- Очки, рейтинги, соревнование между учениками — слабых это отталкивает.
- Подбор предложений «по интересам», как у NoRedInk: по отзывам, быстро приедается.
- Автопроверку свободного текста (сочинения, изложения) — только образцы и критерии самопроверки.
- Всё, что требует интернета или аккаунта для основной работы.

## 5. Вопросы владельцу
1. Для каких классов учебник (5–9? 10–11?) и по какой программе работает школа — нужна ли привязка «глава → класс»?
2. К какому экзамену готовятся ученики (ОГЭ/ЕГЭ, национальный тест, вступительные)? От этого зависит формат экзаменационных заданий.
3. Нужно ли учителю видеть результаты класса? Если хватает кода проверки — обходимся без сервера; если нужен журнал — это отдельный большой шаг.
4. Аудиодиктант нужен? Голос на телефонах учеников — системный: проверим, есть ли русский голос на их Android.
5. Мотивация: «дни подряд» — да или нет?
