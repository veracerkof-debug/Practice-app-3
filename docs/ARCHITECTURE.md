# Архитектура

## Принцип

Учебник — **один самодостаточный HTML-файл** (`dist/index.html`, около 520 КБ): без сервера, без сборщиков, без библиотек и без запросов в сеть. Поэтому его можно:
- выложить как статический сайт (GitHub Pages);
- завернуть в Android-приложение (WebView / Capacitor / TWA) без переделки;
- открыть офлайн.

Исходники разбиты на модули в `src/`; `tools/build.py` склеивает их **в фиксированном порядке** в шаблон `src/index.html` (метки `/*@CSS*/` и `/*@JS*/`). Весь JS выполняется внутри одной функции `(()=>{ … })()`, поэтому модули видят друг друга без import/export; объявленное раньше доступно позже (функции — везде, константы — после объявления).

**Две версии.** `build.py` собирает версию ученика (`dist/index.html`, `www/index.html` — сайт и Android): поля `key` упражнений в тетрадь вырезаются из файла, флаг `TEACHER=false`. И версию учителя (`dist/teacher.html`, `TEACHER=true`) — с ответами; на сайт она не выкладывается, а прикладывается к запуску Actions «Публикация на GitHub Pages» (файл `uchebnik-dlya-uchitelya`).

## Модели данных

### Оглавление курса — `PARTS` (store.js)
```js
{n:5, t:'Морфология', c:'var(--T)', ch:[
  {id:'prichastie', t:'Причастие', s:'подзаголовок', ready:1, deck:'nn'?}, …]}
```
`ready:1` — глава готова. `id` совпадает с ключом в `CHAPTERS`. Нумерация «5.6» вычисляется по положению.

С 12.11.2026 **оглавление = линейный маршрут изучения** (решение владельца, `docs/plans/struktura.md`, раздел 9): 9 разделов, 51 глава (готовых — 22, остальные «готовится»), главы идут подряд от звука к тексту, синтаксис — после всей морфологии. Поэтому кнопки «‹ ›» и «Продолжить» (по `ALLCH`) ведут ученика по маршруту. Порядок изучения в корпусе (`COURSE_ORDER`, `levels.js`) совпадает с оглавлением; `orderCheck` в самопроверке следит, что в нём есть все главы. Цвета разделов — токены `--A --V --M --tint --T --S --K --D` (`base.css`). Id готовых глав не меняются — от них зависят прогресс ученика и ссылки `#ch-…`, `#ex-…`.

### Глава — `CHAPTERS[id]`
```js
{id, kicker:'Морфология', t:'Причастие', s:'подзаголовок', src:'По книгам: …',
 lessons:[Lesson], bank:[BankItem], classic:[Exercise], lnames:['', 'Урок 1', …], bookref:{1:'…'}, table:'<html>'?}
```
Глава собирается так: `const PR={…lessons}` → `Object.assign(PR,{bank,classic,lnames,bookref})` → `CHAPTERS.prichastie=PR`.

### Урок — `Lesson`
| поле | что это |
|---|---|
| `id` | `pr1`, `nn3` … (уникален во всём учебнике, используется в ссылках и прогрессе) |
| `t` | название |
| `h` | **полная теория** (HTML). Подзаголовки — `<h4>` (попадают в оглавление). Примеры — `<span class="ex">`, морфемы/буквы — `<b class="m">`, блоки — `<div class="bins bkey"><div class="h">Главное</div>…</div>` (главное, «Запомнить»), `bins bnorm` (норма, «Частая ошибка», «Два взгляда»), `bins btip` (совет, «Интересно») |
| `lite` | короткая теория для режима «Проще» |
| `deep` | «Тонкости» — сворачиваемый блок для сильных |
| `hint` | одна фраза-суть урока |
| `easy` | «Проще» — объяснение на пальцах (сворачиваемое) |
| `fix` | «Если не получается» — что делать |

Метки внутри `h`: `{{lab:ID}}` — интерактивная схема из `LABS`; `{{table}}` — `chapter.table`; `[[termId|слово]]` — ручная ссылка на термин (обычно не нужна: термины связываются автоматически, см. ниже).

### Интерактивная схема — `LABS[id]`
Функция без аргументов, возвращает HTML; состояние — в переменных модуля. Перерисовка: `relab(id)`. Регистрация: `Object.assign(LABS,{parse:parseHTML,…})`. Клики обрабатываются в `screens.js` по своим `data-*` (например, `data-parse`, `data-matrix`).

### Задание тренажёра — `BankItem`
В исходниках — массив `[w, a, why, l, opts?, q?]`, затем `.map` в объект `{id,w,a,why,l,opts,q}`.
- `w` — слово/фраза; `_` — место пропуска (тогда режим «вставить»). Без `_` — вопрос с выбором (`w` = формулировка).
- `a` — верный ответ (строго один из `opts`).
- `opts` — варианты (по умолчанию `['н','нн']`). Задания с одинаковым набором `opts` группируются в режим «Столбики».
- `l` — номер урока (1…), `q` — подпись типа задания.

### Классическое упражнение — `Exercise`
```js
{l:3, st:4, task:'Вставить пропущенные буквы. Объяснить.', obr:'Образец: …'?, body:'1. Кож..ный ремень. 2. …', key:'1. Кожаный. 2. …', n?}
```
`st` — сложность 1–5 (5 — диктант/сочинение). `..` в `body` — пропуск. `n` проставляется автоматически по порядку. В режиме «Проще» образец открыт.

### Глоссарий — `GLOSS[id]`
```js
prich:{t:'Причастие', d:'определение', ex:'пример', cat:'Морфология', f:'причасти[а-яё]*', at:'pr1', see:['deepr','pril']}
```
- `f` — регулярное выражение форм термина для **автоссылок** (первое упоминание в каждом уроке). Обязательно без ложных срабатываний («вид», «время», «род» — только в сочетаниях). `\w` не ловит кириллицу — писать `[а-яё]*`.
- `at` — урок, где понятие **впервые по маршруту объясняется** (полно или справкой; PRINCIPLES §3а, п. 8); пусто — пока нигде. `ch` — глава-«дом», где понятие изучается полностью (может быть ещё не написана): если она не совпадает с главой урока `at`, карточка термина показывает «Изучается полностью: глава …». `base:1` — понятие начальной школы (буква, слово, предложение): справка не нужна. `see` — связанные термины.
- Проверка: `node tools/graph.js --gloss` (у каждого термина есть `ch`; `at` — существующий урок, в котором термин встречается, и не позже главы-дома).
- Категории: `Морфология`, `Морфемика и словообразование`, `Орфография`, `Синтаксис и пунктуация`, `Общие понятия`.

### Словарик правописания — `WORDS`
```js
{w:'деревянный', n:'почему так пишется', tag:'исключение|пара|запомнить|сочетание|правило', at:'nn1', hl:'нн', pair:'…'?}
```
`hl` — подстрока, которая подсвечивается (первое вхождение). Ударения берутся из колоды `DECKS.udar`.

### Умный словарь — `DICT` (см. docs/DICTIONARY.md)
```js
{w, s:'деревя́нный', pos, gram, mean:[{d,ex}], morph:[['root','дерев'],['suf','янн'],['end','ый']], osn:'деревянн',
 form:{from:'дерево',how:'суффиксальный',aff:'-янн-'}, chain:[…], nest:[['сущ.',[…]],…],
 syn:[], ant:[], par:[{w,d}], phr:[{p,d}], orth:[{t,at}], note}
```
Типы морфем: `pref`, `root`, `suf`, `end` (`''` — нулевое), `post`, `link`. `FORMS[w]` — таблицы форм (`t:'adj'|'noun'|'verb'|'none'`).

### Состояние — `S` (localStorage `rus-uchebnik-v1`)
`done` (пройденные уроки и упражнения `cl-<глава>-<n>`), `tests` (`'<глава>:<урок|final>' → {best,last,tries,at}`), `tlog` (журнал попыток тестов, последние 300: `{t,g,p,n,at,sec}` — для будущей синхронизации), `cards` (Leitner: `{b,due,seen}`), `view` (`book|gloss|dict|cards`), `tab` (`theory|train|classic|tests`), `easy` (режим «Проще»), `cls` (фильтр звёзд), `last` (последний урок), `tocOpen` (раскрытые главы в оглавлении).

Поля статистики (добавлены 11.11.2026; **только добавляются** — старые сохранения открываются без миграции): `prof` (`{name,sur,cls}` — имя, фамилия, класс), `time` (`{'ГГГГ-ММ-ДД': секунды}` — активное время, 120 дней), `ans` (`{<id урока>: {r,n,ok,at,m}}` — ответы тренажёра: `r` — последние 20, «1» — верно с первой попытки; `m` — ступень «знакомо» достигнута), `seen` (открытые уроки), `at` (`{ch,tab,l}` — где остановился), `recent` (последние 3 задания `#ex-…`: `{ch,r,at}`).

## Маршруты

`#home` — главная (и адрес без хэша); `#toc` — содержание учебника (`#glossary`, `#dict`, `#cards` — его вкладки); `#me` — кабинет «Мои результаты»; `#ch-<id>[/<вкладка>[/<урок>]]`, `#ex-<id>-<номера>`, `#deck-<id>`, `#study-<id>`, `#w-<слово>` — как раньше. «Назад» из содержания и кабинета — на главную, из главы — в содержание.

## Статистика на устройстве (stats.js) — главная и кабинет (home.js)

- **Пороги** — константы `ST` в начале `stats.js` (предложение, решает владелец).
- **Ответы тренажёра**: `statAns(глава, урок, верно)` вызывается из `trScore()` (`trainer.js`) и из проверки механик (`mech.js`) — один раз на задание, первая попытка. Повтор ошибок в той же серии (`TR.run.re`, `t.retry`) не записывается.
- **Ступень урока** — `lessonLevel(id)` → `{lv,word,g,weak,…}`: 0 «не начато», 1 «начато» (урок открыт, отмечен или есть ответы), 2 «знакомо» (≥10 ответов и ≥70 % верных из последних 20; достигнутая ступень не отнимается), 3 «уверенно» (последняя оценка за тест урока 4–5). Глава освоена — `chTestsDone`.
- **Стоит повторить** — `weakLessons(n)`: ≥8 ответов и <70 % верных из последних 20 (если тест урока не сдан на 4–5) либо последняя оценка за тест — 2.
- **Не доведено до конца** — `unfinished(n)`: начатые главы, где сданы не все тесты.
- **Активное время**: в `S.time` идут только промежутки между действиями ученика (нажатие, ввод, прокрутка, касание) короче 5 минут и только при видимой вкладке; запись в localStorage — не чаще раза в 45 с и при уходе со страницы.
- **Копия данных**: `{app:'rus-uchebnik',v:1,by,at,data:S}` — файл `uchebnik-<имя>-<дата>.json` или текст; `bkRead()` проверяет и показывает, чья копия и что в ней, `bkApply()` заменяет `S` (через `normS()`), `wipeAll()` стирает всё.
- В самопроверке (`?selftest`) эти функции доступны в `window.__T`.

## Навигация и ссылки (nav.js)

После отрисовки теории `enhance()` обходит текстовые узлы уроков (кроме схем, кнопок, заголовков, примеров `.ex`) и:
1. превращает «урок 4», «в уроках 1–2» в ссылки на уроки этой главы, «в главе «Н и НН»» — в ссылку на главу;
2. через `termsIn()` связывает **каждое упоминание** термина глоссария (длинные термины — раньше коротких; пересечения не допускаются).

**Общий корпус** (`src/data/corpus/`): `CORPUS_S` (предложения), `CORPUS_T` (связные тексты — отрывки классики; `corpusTexts()`), `CORPUS_W` (слова), `levels.js` — `COURSE_ORDER` (= оглавление), `OPORY` (опоры глав: `need` — главы, которые должны быть пройдены раньше, `prop` — более поздние темы, о которых глава даёт справку; из них — блок «Что нужно знать» и проверка графа понятий: `tools/lib/graph.js`, `node tools/check-chapter.js <id>`, сводка — `node tools/graph.js`), `PROP_TOPIC` (пропедевтика: глава, которая даёт справку о более поздней теме, получает доступ к её материалу; сейчас «Причастие» и «Деепричастие» — члены предложения), `tKnown()`, `corpusUnits()`, `corpusSents(тема,need)`, `corpusWords(тема,f)`, `RAZBOR`. Механики берут материал только через эти функции — так соблюдаются уровни доступа.

**Орфограммы корпуса**: `ORTHO_R` (`orthograms.js`), пометка `ор:` в предложениях; `orthPool(c,les)` в `mech.js` — слова с орфограммами темы главы.

**Механики тренажёра** (`src/js/core/mech.js`): реестр `MECH` — у каждой механики `gen(c,les)` (задание из `c.wk` главы), `body(t)`, `ready(t)`, `grade(t)`, `act(t,d)`; клики — по `data-ma`, проверка — `data-mcheck`. Задание — простой объект (JSON), копия `orig` нужна для повтора ошибки. Тренажёр (`trainer.js`) смешивает механики со старыми заданиями банка в режиме `all`. Адрес с `?selftest` открывает `window.__T` для самопроверки в тестах.

`termsIn(root)` вызывается и для упражнений, тренажёра и тестов. Не трогает примеры `.ex`, морфемы, кнопки и варианты ответов, схемы, материал упражнений `.cbody`, шапку главы (`TSKIP` в `nav.js`). Термин выглядит как обычный текст с пунктиром цвета акцента; при наведении — подсветка.
`linkWords()` в `dictionary.js` связывает слова в примерах `.ex` со статьями умного словаря (по всем формам из `FORMS`).

Индекс `TUSE[termId]` — в каких уроках встречается термин (для шторки «Встречается ещё» и «Термины главы»).

## Стиль и вёрстка

- Цвета — только токены из `:root` (`--bg --cell --fill --fill2 --sep --ink --l2 --tint --tint-text --on-tint --red --T --S --D --V --A`), тёмная тема — через `prefers-color-scheme` и `[data-theme]`.
- Ширина контента — до 860 px, текст уроков — до 72ch. Все блоки должны помещаться в 360 px. Широкие таблицы — в `.tblw` (горизонтальная прокрутка) или с переключателем колонок (как формы слова).
- Кнопки — не меньше 36–44 px по высоте. Анимации отключаются при `prefers-reduced-motion`.
