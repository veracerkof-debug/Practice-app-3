# Архитектура

## Принцип

Учебник — **один самодостаточный HTML-файл** (`dist/index.html`, около 520 КБ): без сервера, без сборщиков, без библиотек и без запросов в сеть. Поэтому его можно:
- выложить как статический сайт (GitHub Pages);
- завернуть в Android-приложение (WebView / Capacitor / TWA) без переделки;
- открыть офлайн.

Исходники разбиты на модули в `src/`; `tools/build.py` склеивает их **в фиксированном порядке** в шаблон `src/index.html` (метки `/*@CSS*/` и `/*@JS*/`). Весь JS выполняется внутри одной функции `(()=>{ … })()`, поэтому модули видят друг друга без import/export; объявленное раньше доступно позже (функции — везде, константы — после объявления).

## Модели данных

### Оглавление курса — `PARTS` (store.js)
```js
{n:4, t:'Морфология', c:'var(--T)', ch:[
  {id:'prichastie', t:'Причастие', s:'подзаголовок', ready:1, deck:'nn'?}, …]}
```
`ready:1` — глава готова. `id` совпадает с ключом в `CHAPTERS`. Нумерация «4.6» вычисляется по положению.

### Глава — `CHAPTERS[id]`
```js
{id, kicker:'Морфология', t:'Причастие', s:'подзаголовок', src:'По книгам: …',
 lessons:[Lesson], bank:[BankItem], classic:[Exercise], lnames:['', 'Урок 1', …], bookref:{1:'…'}, table:'<html>'?}
```
Глава собирается так: `const PR={…lessons}` → `Object.assign(PR,{bank,classic,lnames,bookref})` → `CHAPTERS.prichastie=PR`.

### Урок — `Lesson`
| поле | что это |
|---|---|
| `id` | `pr1`, `nn3` … (уникален во всём учебнике, используется в ссылках и прогрессе) |
| `t` | название |
| `h` | **полная теория** (HTML). Подзаголовки — `<h4>` (попадают в оглавление). Примеры — `<span class="ex">`, морфемы/буквы — `<b class="m">`, блоки — `<div class="bins bkey"><div class="h">Главное</div>…</div>` (главное, «Запомнить»), `bins bnorm` (норма, «Частая ошибка», «Два взгляда»), `bins btip` (совет, «Интересно») |
| `lite` | короткая теория для режима «Проще» |
| `deep` | «Тонкости» — сворачиваемый блок для сильных |
| `hint` | одна фраза-суть урока |
| `easy` | «Проще» — объяснение на пальцах (сворачиваемое) |
| `fix` | «Если не получается» — что делать |

Метки внутри `h`: `{{lab:ID}}` — интерактивная схема из `LABS`; `{{table}}` — `chapter.table`; `[[termId|слово]]` — ручная ссылка на термин (обычно не нужна: термины связываются автоматически, см. ниже).

### Интерактивная схема — `LABS[id]`
Функция без аргументов, возвращает HTML; состояние — в переменных модуля. Перерисовка: `relab(id)`. Регистрация: `Object.assign(LABS,{parse:parseHTML,…})`. Клики обрабатываются в `screens.js` по своим `data-*` (например, `data-parse`, `data-matrix`).

### Задание тренажёра — `BankItem`
В исходниках — массив `[w, a, why, l, opts?, q?]`, затем `.map` в объект `{id,w,a,why,l,opts,q}`.
- `w` — слово/фраза; `_` — место пропуска (тогда режим «вставить»). Без `_` — вопрос с выбором (`w` = формулировка).
- `a` — верный ответ (строго один из `opts`).
- `opts` — варианты (по умолчанию `['н','нн']`). Задания с одинаковым набором `opts` группируются в режим «Столбики».
- `l` — номер урока (1…), `q` — подпись типа задания.

### Классическое упражнение — `Exercise`
```js
{l:3, st:4, task:'Вставить пропущенные буквы. Объяснить.', obr:'Образец: …'?, body:'1. Кож..ный ремень. 2. …', key:'1. Кожаный. 2. …', n?}
```
`st` — сложность 1–5 (5 — диктант/сочинение). `..` в `body` — пропуск. `n` проставляется автоматически по порядку. В режиме «Проще» образец открыт.

### Глоссарий — `GLOSS[id]`
```js
prich:{t:'Причастие', d:'определение', ex:'пример', cat:'Морфология', f:'причасти[а-яё]*', at:'pr1', see:['deepr','pril']}
```
- `f` — регулярное выражение форм термина для **автоссылок** (первое упоминание в каждом уроке). Обязательно без ложных срабатываний («вид», «время», «род» — только в сочетаниях). `\w` не ловит кириллицу — писать `[а-яё]*`.
- `at` — урок, где термин объясняется; `see` — связанные термины.
- Категории: `Морфология`, `Морфемика и словообразование`, `Орфография`, `Синтаксис и пунктуация`, `Общие понятия`.

### Словарик правописания — `WORDS`
```js
{w:'деревянный', n:'почему так пишется', tag:'исключение|пара|запомнить|сочетание|правило', at:'nn1', hl:'нн', pair:'…'?}
```
`hl` — подстрока, которая подсвечивается (первое вхождение). Ударения берутся из колоды `DECKS.udar`.

### Умный словарь — `DICT` (см. docs/DICTIONARY.md)
```js
{w, s:'деревя́нный', pos, gram, mean:[{d,ex}], morph:[['root','дерев'],['suf','янн'],['end','ый']], osn:'деревянн',
 form:{from:'дерево',how:'суффиксальный',aff:'-янн-'}, chain:[…], nest:[['сущ.',[…]],…],
 syn:[], ant:[], par:[{w,d}], phr:[{p,d}], orth:[{t,at}], note}
```
Типы морфем: `pref`, `root`, `suf`, `end` (`''` — нулевое), `post`, `link`. `FORMS[w]` — таблицы форм (`t:'adj'|'noun'|'verb'|'none'`).

### Состояние — `S` (localStorage `rus-uchebnik-v1`)
`done` (пройденные уроки и упражнения `cl-<глава>-<n>`), `cards` (Leitner: `{b,due,seen}`), `view` (`book|gloss|dict|cards`), `tab` (`theory|train|classic`), `easy` (режим «Проще»), `cls` (фильтр звёзд), `last` (последний урок), `tocOpen` (раскрытые главы в оглавлении).

## Навигация и ссылки (nav.js)

После отрисовки теории `enhance()` обходит текстовые узлы уроков (кроме схем, кнопок, заголовков, примеров `.ex`) и:
1. превращает «урок 4», «в уроках 1–2» в ссылки на уроки этой главы, «в главе «Н и НН»» — в ссылку на главу;
2. связывает **первое упоминание** каждого термина глоссария в уроке (длинные термины — раньше коротких).
`linkWords()` в `dictionary.js` связывает слова в примерах `.ex` со статьями умного словаря (по всем формам из `FORMS`).

Индекс `TUSE[termId]` — в каких уроках встречается термин (для шторки «Встречается ещё» и «Термины главы»).

## Стиль и вёрстка

- Цвета — только токены из `:root` (`--bg --cell --fill --fill2 --sep --ink --l2 --tint --tint-text --on-tint --red --T --S --D --V --A`), тёмная тема — через `prefers-color-scheme` и `[data-theme]`.
- Ширина контента — до 860 px, текст уроков — до 72ch. Все блоки должны помещаться в 360 px. Широкие таблицы — в `.tblw` (горизонтальная прокрутка) или с переключателем колонок (как формы слова).
- Кнопки — не меньше 36–44 px по высоте. Анимации отключаются при `prefers-reduced-motion`.

## Android

План: обернуть `dist/index.html` в Capacitor (или TWA, если будет сайт на GitHub Pages). Прогресс уже в localStorage; при переходе на приложение — сохранить тот же ключ.
