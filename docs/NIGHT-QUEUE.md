# Очередь ночной работы

Ночная работа: **каждую ночь с 1:00 до 5:00 по Самарканду** (решение владельца). Работа — строго по `docs/PRINCIPLES.md`.
Каждая ночь берёт задачи сверху вниз, доводит каждую **до конца** (включая автозамеры, две независимые проверки — «строгий филолог» и «ученик без ключа» — исправления, зелёные тесты, слияние PR) и только потом берётся за следующую. Незаконченная к 5:00 задача остаётся первой со статусом «в работе» и подробной заметкой, на чём остановились (ветка, что сделано, что осталось). Новое не начинается позже 4:15.

Статусы: ⏳ ждёт · 🔧 в работе · ✅ готово (дата).

## Очередь
1. ⏳ **Аудит «Причастия» — сделать главу образцом.** Проверить всё (теорию, «Проще», 170 заданий тренажёра, 40 упражнений, тесты, механики, корпус) по стандарту задания `PRINCIPLES.md` §4–6: один навык, граница знаний, однозначность, естественность, посильность, пары «почти-примеры», ловушки, формулировки, разнообразие (повторы слов и корней), пропорции видов и звёзд. Сначала — автоматический отчёт-замер (скрипт в `tools/audit/`), затем две независимые проверки, затем исправления. Добавить: задания «найти орфограмму / найти, где нужно думать», порядок «блок → вперемешку» в тренажёре. Трудные упражнения (★★★★–★★★★★) — в большинстве на материале классики в общественном достоянии (`PRINCIPLES.md` §6.2). Не менять номера упражнений (`n`) — добавлять новые следующими номерами.
2. ⏳ **Тесты «Н и НН»** — по образцу «Причастия» (6 уроков + итоговый), с проверками.
3. ⏳ **Аудит «Н и НН»** по тому же стандарту, что и «Причастие».
4. ⏳ **Связные тексты в общем корпусе** (`CORPUS_T`): в основном отрывки классики в общественном достоянии (с автором), полная разметка по предложениям; механика «Текст с пропусками»; уровни доступа; проверки.
5. ⏳ **Глава «Деепричастие»** по образцу «Причастия»: уроки (`h`, `lite`, `deep`, `hint`, `easy`, `fix`), схемы, банк тренажёра, механики, упражнения в тетрадь (полный спектр), тесты, предложения в корпус, термины в глоссарий, подключение; проверки. Можно частями за несколько ночей.
