# Продукт: концепция и решения

## Для кого и зачем

Школьники, которые **учат темы и делают домашку**. Учебник «для всех»: им пользуются и способные ученики, и те, кому трудно. Поэтому:
- полный учебник со всеми правилами, исключениями и тонкостями — для тех, кто хочет знать всё;
- переключатель **«Проще»** — короткие объяснения, образцы, подсказки после ошибки — для тех, кому трудно. (Рабочее название — «режим для хлебушков»; в интерфейсе — только «Проще».)

Учитель (владелец) использует его на уроках и для домашних заданий: «упражнения 12–15 из главы 4.6».

Платформы: веб-версия на GitHub (GitHub Pages) и приложение для Android.

## Принятые решения (по порядку обсуждения)

1. Учебник собирается **из книг владельца** — «идеальный учебник из всех учебников» — и полностью пересказывается (авторское право).
2. Два способа учить: **классический учебник** и **карточки** (интервальное повторение).
3. Дизайн — по мотивам другого приложения владельца (Melete): брать подходящее, не копировать.
4. Интерактивные упражнения вынесены **отдельно** от теории (вкладка «Тренажёр»), и добавлено **много классических упражнений в тетрадь** (вкладка «Упражнения») — их больше, чем интерактивных.
5. Вместо «уровней» — **один полный учебник + режим «Проще»**.
6. Глава «Причастие» сделана развёрнуто, с максимумом интерактивных схем (кластер признаков, таблица четырёх клеток, конструктор образования, пошаговый выбор гласной, склонение, НЕ, запятые) — это **эталон для всех глав**.
7. Сложность упражнений — **5 звёзд** (5 — самое сложное).
8. **Кликабельность и навигация:** любой термин открывает карточку с определением и ссылками на уроки; перекрёстные ссылки; красивое оглавление; глоссарий; словарик со всеми нужными словами.
9. **Умный словарь**: лексика, морфемика, словообразование и всё остальное в одной карточке слова. Пилот — 50 слов; владельцу понравилось.
10. Вёрстка должна быть **одинаково удобной на компьютере и телефоне**.
11. **Упражнения — полный спектр и комплекс**: все виды по всем параметрам (охват, вид действия, материал, сложность), узкие и широкие, комплексные; выбор шире, чем у Розенталя. Подробно — `docs/CONTENT-GUIDE.md`, раздел 5.
12. **Домашка без «домиков».** Отдельно домашнее задание не помечается. Вместо этого у каждого упражнения постоянный номер, а ученик открывает ровно заданное: вводит номера («12–15») или открывает ссылку от учителя — на экране остаются только эти упражнения, фильтры не мешают, сверху крупно написано, какая это глава. Номера чужих книг подписаны «по той книге».
13. **Журнал и сервер учителя** (после учебника): у каждого учителя свой сервер — приложение для Windows/macOS/Linux; данные учеников только там. Кабинет: классы, аккаунты учеников, оценки, посещаемость, заметки, КТП, статистика, откат статистики, рейтинг (средний балл, время, старание). Ссылки для родителей создают ученик и учитель. Подробно — `ROADMAP.md`, этапы B–D.
14. **Тесты** — отдельный формат и банк, глава завершается только после тестов.
15. **Защита данных пользователей.** Никаких конфиденциальных данных не просим — у учеников только имя и фамилия. Базовая защита обязательна и настолько хорошая, насколько можем: шифрованная передача (HTTPS), хеши паролей, шифрование базы и копий, доступ по ролям, отзываемые ссылки для родителей, без сторонней аналитики. Подробно — `ROADMAP.md`.
16. **Не готовим к конкретным экзаменам** (11.11.2026). К ОГЭ, ЕГЭ и национальному сертификату учебник специально не готовит. Задания экзаменационного типа — «Задания для абитуриентов», без названий экзаменов и номеров заданий. Из всех глав упоминания экзаменов убраны.
17. **На будущее** (11.11.2026; записано, детали владелец решит позже): кабинет ученика; главная страница; режим «для продвинутых» (12.11.2026: больше теории, сложнее задания, упражнения и тренажёр); доработка дизайна — более интерактивный, более «нативный», эстетически красивый. Учебник должен быть не только хорошо проработан, но и эстетически приятен. Подробнее — `ROADMAP.md`.

## Экраны

- **Главная**: поиск (главы, уроки, разделы, термины, слова), вкладки «Учебник · Глоссарий · Словарь · Карточки».
  - «Учебник» — «Продолжить», статистика, оглавление (разделы → главы → уроки → подразделы), справочник.
- **Глава**: шапка (номер, название, «Проще», «Содержание»), вкладки «Теория · Тренажёр · Упражнения».
  - Теория — уроки со схемами; под уроком «Практика по уроку», «Проще», «Если не получается», «Тонкости», «Урок пройден».
  - Тренажёр — выбор уроков, режима (по одному / столбики / найти ошибку / вперемешку) и числа заданий.
  - Упражнения — поле «Номер» и карта номеров по урокам (на компьютере — в боковой колонке, на телефоне — ещё и в «Содержании»), фильтры по уроку, звёздам и «Только невыполненные», образец, ключ, «Выполнено», ссылка на упражнение. Вид «задание» (`#ex-<глава>-12-15`) показывает только заданные номера.
- **Шторка термина**, **Содержание главы**, **Карточка слова**, **Колода карточек**.

## Стиль текста

- Объяснения — коротко, по делу, с примерами; без «воды».
- Задания — инфинитивом («Вставить…, объяснить…»).
- Определения в глоссарии — для ученика 11–15 лет.
