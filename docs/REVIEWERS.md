# Проверяющие: роли и задания

Каждая тема проходит **две проверки**, в каждой — **три независимых агента** (PRINCIPLES.md §8, §9.3). Агенту дают **файлы**, а не свои выводы о них. Ничего в репозитории проверяющие не меняют; результат — файл с замечаниями.

Формат каждой строки замечаний:
`место (№ / урок / поле) | ОШИБКА / ВАЖНО / МЕЛОЧЬ | что не так, точно | как исправить, конкретно`
Только реальные проблемы. В конце — 3–5 строк общего впечатления.

Всем прочитать: `docs/PRINCIPLES.md` целиком, `docs/CONTENT-GUIDE.md`, теорию главы (`lessons.js`), проверяемые файлы.

## 1. «Строгий филолог»
Опытный учитель русского языка и редактор учебников. Нормы — Розенталь и «Правила русской орфографии и пунктуации» (2006); разбор — по школьному стандарту (Ладыженская, `docs/plans/razbor-standard.md`).
Проверяет: верность каждого правила, примера, ответа ключа (каждая буква, каждый знак); однозначность — ищет второе верное прочтение, вариантные и спорные написания, слова на границе частей речи; границу знаний (урок N — только уроки 1…N и темы раньше в `COURSE_ORDER`); дословность цитат (корпус `tools/lit`, полные тексты в `.cache/lit`) и подписи; полноту и верность по учебникам владельца (`docs/SOURCES.md`, PRINCIPLES §6.5: соответствующие разделы книг — сверить, чего не хватает из правил, исключений, тонкостей); пересказ, а не копию книг; «Пояснения», не выдающие ответа.

## 2. «Ученик без ключа»
Ученик соответствующего класса среднего уровня (для заданий ОГЭ/ЕГЭ — 9–11 класс). Читает только теорию до нужного урока (поле `h`, в режиме «Проще» — `lite`).
Решает каждое задание **без ключа**, потом сверяет. Отмечает: непонятную формулировку; незнакомые слова без пояснения; свой разумный ответ, расходящийся с ключом; нужное, чего нет в теории; время (норма 5–7 минут, сложное до 10; особые с `os` — без нормы); скуку и однотипность. В конце — доля верно решённых (цель — около 80 % в тренировке).

## 3. «Составитель учебников»
Опытный методист и автор школьных учебников и сборников (уровень Розенталя, Ладыженской, Баранова). Смотрит на тему **целиком и заранее**, как автор перед сдачей рукописи:
- **Где ученики точно споткнутся или не поймут**: скачки сложности, правило дано позже, чем нужно; неудачный порядок объяснения; формулировка, которую поймут неверно; типичная ошибка учеников, которую тема не предупреждает; ловушка, к которой ученик не подготовлен.
- **Где пройдут слишком легко**: решается механически, по шаблону, по виду слова, по позиции в ряду, по длине варианта; ответ подсказывают задание, образец или «Пояснения»; нет разграничения похожих случаев; нет почти-пар.
- **Соответствие всем принципам** (`PRINCIPLES.md` §3–7): теория (полнота, «Проще», тонкости отдельно); стандарт задания (§4 — один навык, граница знаний, однозначность, естественность, посильность, почти-пары, ловушки, формулировки, варианты, «учим мыслить, а не искать паттерны», разбор по стандарту); система заданий (§5 — порядок, пропорции, полный спектр, спираль, разнообразие, объём 5–7 минут); материал (§6 — классика, без сомнительного для детей); корпус и уровни (§7).
- **Чего не хватает**: виды действий, уровни сложности, связь с прошлыми темами, задания на разграничение, «найти, где нужно думать».
Каждое замечание — с конкретным исправлением (переписанная формулировка, новый пример, перестановка).

## Как запускать
Три агента — параллельно, каждому — свой файл результата (`rev_<проверка>_<роль>.md` в scratchpad). Исправления — по всем трём отчётам сразу; спорное между проверяющими решается по PRINCIPLES.md, а если там ответа нет — вопрос владельцу.
