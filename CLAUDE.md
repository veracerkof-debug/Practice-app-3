## Что это

**Интерактивный учебник русского языка для школьников** («Русский язык»). Автор и владелец — Александр Ким, учитель русского языка (Самарканд). Учебник «для всех»: им пользуются и сильные, и слабые ученики — когда учат темы и делают домашку. Будет жить на GitHub (веб-версия) и как приложение для Android.

Содержание собрано из книг владельца (Розенталь, Адамчик, Наумова, Сидорова, Классический справочник, сборники упражнений — см. `docs/SOURCES.md`) и **полностью пересказано своими словами**: копировать тексты книг нельзя (авторское право), брать можно правила, факты, примеры-слова.

## Главные решения владельца (не менять без него)

1. **Полный учебник + режим «Проще».** Основной режим — «самый полный сборник»: все правила, исключения, тонкости, таблицы и схемы. Второй режим включается переключателем «Проще» в шапке главы: короткие объяснения (`lite`), открытый образец в упражнениях, подсказка после первой ошибки в тренажёре. Внутреннее рабочее название второго режима — «режим для хлебушков»; **в интерфейсе его никак не называть**, только «Проще».
2. **Упражнения двух видов, отдельно от теории:** вкладка «Тренажёр» (интерактивные задания из банка) и вкладка «Упражнения» (классические, в тетрадь, с ключами). Классических должно быть **больше**, чем интерактивных.
3. **Сложность — 5 звёзд**: ★ очень легко … ★★★★★ — самое сложное (диктант, сочинение, связный текст). Есть фильтр по звёздам.
4. **Максимум интерактивных схем** в теории: кластеры, таблицы, пошаговые алгоритмы, конструкторы (см. главу «Причастие» — эталон).
5. **Кликабельность:** термин в тексте → карточка с определением и ссылками на уроки; «в уроке 6», «в главе «Н и НН»» — ссылки; слова из умного словаря — ссылки на карточку слова.
6. **Удобно и на телефоне, и на компьютере.** Ничего не должно вылезать за границы (проверка — `tools/test/layout.js`).
7. **Нормы — по Розенталю** и «Правилам русской орфографии и пунктуации» (2006). Спорное не подавать как единственно верное; варианты с двумя допустимыми написаниями в задания не брать.
8. Дизайн частично взят из другого приложения владельца (Melete): тёплая палитра, токены цвета, светлая/тёмная тема. Копировать Melete целиком не нужно.
9. **Упражнения — полный спектр.** Нужны все типы упражнений по всем параметрам: узкие и широкие, по уроку и комплексные, все виды действий, от слов до связного текста, все 5 уровней сложности. Выбор — как у Розенталя, только шире (`docs/CONTENT-GUIDE.md`, раздел 5).
10. **Домашка без «домиков».** Отдельной пометки «на дом» нет. У упражнения постоянный номер (`n` в данных — не менять и не переиспользовать); ученик открывает заданное через поле «Номер» («12–15») или ссылку `#ex-<глава>-12-15` — видны только эти упражнения.
11. **Порядок работы:** сначала хороший учебник (тесты, статистика на устройстве, диктанты, главы), потом сервер учителя (своё приложение для Windows/macOS/Linux, данные только у учителя), кабинет-журнал и синхронизация. Подробно — `docs/ROADMAP.md`.
12. **Тесты** — отдельно от тренажёра: много формулировок вопроса, варианты в случайном порядке, разные форматы; глава завершается только после сданных тестов.
13. **Статистика** — условный показатель вовлечённости, а не оценка: 5 минут без действий не засчитываются; учитель может откатить статистику. Главное — оценки учителя; в рейтинге учитывается старание, а не только время.
14. **Защита данных пользователей — обязательна**, насколько это в наших силах: у учеников только имя и фамилия; только HTTPS; хеши паролей и PIN; шифрование базы и резервных копий; доступ строго по ролям; длинные отзываемые ссылки для родителей; никакой сторонней аналитики. Подробно — `docs/ROADMAP.md`, раздел «Защита данных пользователей».
15. **Две версии: для ученика и для учителя** (04.11.2026). В версии ученика (сайт, Android) **ответов к упражнениям в тетрадь нет ни в каком виде** — `tools/build.py` вырезает поля `key` из файла. Версия для учителя (`dist/teacher.html`, с ответами) на сайт не выкладывается: её даёт запуск Actions (файл `uchebnik-dlya-uchitelya`), позже — сервер учителя. В коде — флаг `TEACHER`.
16. **Не готовим к конкретным экзаменам** (11.11.2026). Учебник не готовит специально к ОГЭ, ЕГЭ и национальному сертификату. Задания экзаменационного типа — в рубрике «Задания для абитуриентов», без названий экзаменов и номеров заданий (`PRINCIPLES.md` §5.10).
17. **Главная страница и кабинет ученика** (11.11.2026, первая версия): учебник открывается на главной (`#home`: «Продолжить», кнопка «Учебник», слабые и недоведённые темы, неделя, освоено); кабинет «Мои результаты» (`#me`: профиль, темы по ступеням, время, копия данных файлом). Статистика — на устройстве (`src/js/core/stats.js`: активное время с правилом 5 минут, ответы тренажёра по урокам); без очков, рейтингов и серий. **На будущее — детали владелец ещё решит:** режим посложнее для сильных учеников; доработка дизайна — более интерактивный, «нативный» и эстетически красивый. Без слова владельца не начинать (`docs/ROADMAP.md`, «Решения владельца на будущее»).

## Как общаться с владельцем

- **Работа с GitHub:** владелец просил не ждать его. Изменения — в рабочей ветке, PR в `main`, после зелёных тестов Claude сам сливает PR; сайт обновляется автоматически. Владелец получает готовое.

- По-русски. Claude говорит о себе **в мужском роде** («сделал», «проверил»).
- Владелец ценит, когда работа доведена «почти до идеала», и не любит недоделок. Короткие отчёты: что сделано, что не вошло и почему.
- Учебные формулировки в материалах — утвердительные; в заданиях — повелительные/инфинитивные («Вставить пропущенные буквы»), как в сборниках.

## Устройство кода (коротко)

- Результат — **один самодостаточный файл** `dist/index.html` (HTML + CSS + JS, без зависимостей и сети). Собирается из `src/` скриптом `python3 tools/build.py`. Порядок файлов задан в `tools/build.py` и важен.
- Весь JS работает внутри одной функции `(()=>{ … })()`; модули — это просто склеиваемые куски, без import/export.
- Состояние ученика — `localStorage['rus-uchebnik-v1']` (объект `S`: пройденные уроки, карточки, режим, вкладка, фильтры, последний урок; с 11.11.2026 — профиль `prof`, активное время `time`, ответы тренажёра `ans`, открытые уроки `seen`, недавно заданное `recent`; поля только добавляются).
- Маршруты — через `location.hash`: `#home` (главная, по умолчанию), `#me` (кабинет ученика), `#toc` (содержание), `#glossary`, `#dict`, `#cards`, `#ch-<id>`, `#ex-<id>-<номера>` (например `#ex-prichastie-12-15,18`), `#deck-<id>`, `#study-<id>`, `#w-<слово>`.
- Отрисовка — строками HTML (`render()` в `screens.js`), клики — один делегированный обработчик по `data-*` атрибутам.
- Компьютерная вёрстка (≥1100px) — `src/css/wide.css`: страница до 1240px, в главе слева боковое содержание (`chSide()` в `screens.js`), части курса, глоссарий и словарик — в две колонки. На телефоне этот файл ничего не меняет.

Подробно: `docs/ARCHITECTURE.md`.

## Команды

```bash
python3 tools/build.py            # собрать dist/index.html (ученик, без ответов; + www/index.html для Pages и Android) и dist/teacher.html (учитель, с ответами)
node tools/test/smoke.js          # прогон всех схем, тренажёра, упражнений, навигации (нужен playwright)
node tools/test/layout.js         # ничего не вылезает за границы при 360 / 768 / 1280 px
sh tools/lit/fetch.sh && python3 tools/lit/build.py   # корпус русской классики (~270 тыс. предложений, 24 автора) в .cache/lit
node tools/lit/find.js "<регулярка>" --a "Чехов" --n 40   # поиск предложений для упражнений (уже использованные исключаются)
node tools/check-chapter.js <id>  # автоматическая проверка главы: синтаксис, имена, формат, объём, ключи, тесты, повторы, транскрипция (0 ошибок — условие сдачи)
```
Перед **каждым** коммитом (и в рабочей ветке тоже): сборка + оба теста без ошибок. Новая глава в работе — в `DRAFT` (`tools/build.py`): не входит в сборку, пока не пройдёт проверку и исправление; задание автору главы — `docs/plans/CHAPTER_BRIEF.md`.

## Как делать новую главу

Строго по `docs/PRINCIPLES.md` (стандарт задания, проверка качества) и `docs/CONTENT-GUIDE.md` (форматы). «Причастие» — образец. Кратко: материал из книг → пересказ → уроки (`h`, `lite`, `deep`, `hint`, `easy`, `fix`) → схемы (`labs.js`) → банк тренажёра → классические упражнения со звёздами и ключами → подключить в `tools/build.py` и `CHAPTERS` → **автоматические замеры и одна проверка одним агентом** — «строгий филолог и составитель учебников» в одном (`PRINCIPLES.md`, раздел 8; задания проверяющим — `docs/REVIEWERS.md`) → тесты → глоссарий/словарик дополнить. Порядок по шагам и роли агентов — `docs/WORKFLOW.md`.

## Нельзя

- Копировать тексты учебников и словарей (Ожегов, Тихонов, Ефремова и др.) — только пересказ.
- Вставлять в задания спорные написания или задания с двумя верными ответами.
- Добавлять внешние зависимости в `dist/index.html`. Запросы в сеть разрешены **только для синхронизации с сервером учителя** (этап D в ROADMAP); учебник обязан полностью работать без сети.
- Менять ключ `localStorage` без миграции (у учеников пропадёт прогресс).
