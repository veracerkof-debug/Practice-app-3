# Минималистичный лаунчер

Название пока не выбрано. Это минималистичный главный экран с библейскими символами, греческой типографикой и спокойной анимацией. Сейчас это веб-версия; Android-сборка (Capacitor) собирается в GitHub Actions.

## Возможности

- **Главный экран.** Список приложений с любыми подписями (например, `book · βίβλος`) и метками αʹ βʹ γʹ, I II III или счётчиком запусков. Выравнивание слева, по центру или справа, три размера.
- **Часы, 10 видов:**
  - «Скрижаль» — цифры в рамке;
  - «Кодекс» — Garamond и римские цифры;
  - «Греческие числа» — ιηʹ · μζʹ;
  - «Солнечный круг» — циферблат с греческими числами;
  - «Словом» — время прописью на русском, английском или греческом;
  - «Светила» — час и минута движутся по орбитам, радиусы связаны золотым сечением (Быт 1:16; идея — Orbit-часы из Kvaesitso);
  - «Листы» — перекидные карточки с 3D-переворотом страницы;
  - «Свиток» — цифры прокручиваются по вертикали;
  - «Письмена» — сетка букв, подсвечиваются слова времени с точностью до 5 минут, точки показывают остаток; пустые клетки — греческие буквы (идея QLOCKTWO);
  - «Мозаика» — цифры из смальты 5×7, меняющиеся камешки вспыхивают по очереди, двоеточие мерцает.

  Под часами — литургический час: Утреня, Час третий, Вечерня…
- **Дата** на русском, английском или греческом, рядом греческий день недели. Под датой строка: стих дня (койне + Синодальный перевод или KJV), заметка или текст на койне.
- **Панель значков** до 6 слотов. Каждому слоту назначается значок из базы и действие: команда, запуск приложения или ссылка / deep link / Android intent.
- **База значков:** 57 линейных символов — хризма, ἰχθύς, Альфа и Омега, светильник, менора, скрижали, свиток, гусли, ковчег, якорь, лепта и другие. У каждого есть греческое слово и значение.
- **Жесты:** свайп вверх, вниз, влево, вправо, двойной тап, долгое нажатие, нажатие на часы и на дату. По умолчанию нажатие на часы открывает будильник, на дату — календарь (как в Olauncher). Любому жесту можно назначить любое действие. По умолчанию свайп вверх открывает все приложения.
- **Все приложения:** алфавитный список, поиск. Можно добавлять, изменять и удалять приложения, выносить их на главный экран.
- **Покой** (двойной тап): тёмный экран со свечой, временем и «Σιώπα, πεφίμωσο».
- **Темы:** Свет, Тьма, Пергамент, Авто. **Шрифты** с кириллицей и греческим: Commissioner, EB Garamond, Manrope, JetBrains Mono.
- **Символ на фоне** (по умолчанию выключен): колесо ΙΧΘΥΣ, хризма, Α Ω, звезда, венец — большой бледный знак за часами.
- Вступление «Γενηθήτω φῶς — Да будет свет».
- Экспорт и импорт настроек в JSON.

## Управление

| Действие | Телефон | Компьютер |
|---|---|---|
| Все приложения | свайп вверх | колесо вниз / ↑ |
| Поиск | свайп вниз | начать печатать |
| Настройки | долгое нажатие на пустом месте | — |
| Изменить подпись | долгое нажатие на названии | — |
| Изменить значок панели | долгое нажатие на значке | — |
| Покой | двойной тап | — |
| Закрыть | свайп вниз / «назад» | Esc |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Android

`.github/workflows/Build.yml` собирает отладочный APK (`launcher-debug-apk`). Workflow:

1. собирает веб-версию,
2. добавляет Android-платформу Capacitor,
3. регистрирует приложение как домашний экран (`category.HOME`) и добавляет разрешение `QUERY_ALL_PACKAGES`,
4. собирает APK.

В нативной сборке приложения запускаются по имени пакета через `@capacitor/app-launcher`. В браузере используется ссылка из поля «Ссылка для веба». Следующие шаги: нативный плагин для списка установленных приложений и для запуска `intent:`-ссылок.

## Структура

```
src/
  main.js       сборка, команды, «Покой», вступление, клавиатура
  home.js       главный экран
  clocks.js     виды часов
  gestures.js   жесты
  drawer.js     все приложения, редактор приложения
  settings.js   настройки
  pickers.js    выбор значка и действия
  icons.js      база значков и орнаменты
  scripture.js  стихи, греческие и римские числа, литургические часы, числа словами
  actions.js    команды, шаблоны deep links, запуск
  store.js      состояние (localStorage)
  style.css     дизайн
```

Тексты Писания (койне, Синодальный перевод, KJV) — общественное достояние. Шрифты распространяются под лицензией SIL OFL через @fontsource.
